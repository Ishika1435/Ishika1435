A multi-client SaaS platform for social media content workflows — built for teams managing creators, approvals, and scheduled publishing at scale.

- Multi-tenant architecture with **JWT auth + RBAC** (creator / auditor / admin roles)
- OpenAI-powered **caption generation, content review, and posting-time recommendations**
